# Security Policy

## Supported Versions

Styx applies bug fixes and security patches to the current release line.

## Announcements

Security advisories will be published on GitHub at [gsmlg-dev/styx/security](https://github.com/gsmlg-dev/styx/security).

## Reporting Vulnerabilities

Please disclose security vulnerabilities privately via GitHub at [gsmlg-dev/styx/security/advisories](https://github.com/gsmlg-dev/styx/security/advisories).
